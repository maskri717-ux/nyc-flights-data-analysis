# NYC Flights Data Analysis ✈️

## Overview

This project explores flight performance for flights departing New York City airports using the `nycflights13` dataset in R.

The analysis focuses on identifying patterns associated with flight delays and comparing performance across airlines, airports, routes, and time periods.

## Project Objective

The main question guiding this analysis is:

> **What factors are associated with flight delays for flights departing New York City, and how does performance vary across airlines, airports, routes, and time?**

## Research Questions

1. How are departure and arrival delays distributed?
2. Which airlines have the strongest and weakest delay performance?
3. How does flight performance differ across JFK, LaGuardia, and Newark?
4. How do delays vary by time of day, month, and season?
5. Which routes and destinations experience the most significant delays?
6. What relationship, if any, exists between weather conditions and flight delays?
